# Contributing

## Choose the correct base

| Work | Base and pull request target |
| --- | --- |
| Collection README or documentation | `main` |
| Apartment sales application | `OnlineApartementSalesSystem` |
| Studio/order application | `OnlineStudioAndOrderSystem` |
| Transport application | `OnlineTransportSystem` |

Create your working branch from the matching base. Keep unrelated applications separate. In the pull request, explain the change and include the setup and verification steps used. Add screenshots for visible interface changes when available.

Use local configuration for database credentials. Review files before committing to avoid including personal records or secrets.
